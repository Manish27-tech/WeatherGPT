# 3–5 Minute Judge Demo

## Opening
“WeatherGPT does not replace the official forecast. It adds a conversational decision layer over verified weather metrics.”

## Demo 1 — Farmer
- Select Farmer.
- Ask: “Should I spray pesticides today?”
- Show evidence chips.
- Explain that the engine does not invent temperature/humidity; it fetches them and then applies auditable rules.

## Demo 2 — Disaster
- Select Disaster.
- Ask: “Is there an immediate weather risk?”
- Show risk + evidence + action.
- Mention that official IMD warnings remain authoritative.

## Demo 3 — Voice
- Use microphone input in Chrome/Edge.
- Click Speak advisory.
- Explain that the production architecture can replace browser speech with Whisper + Bhashini.

## Innovation line
“Existing services provide forecasts and advisories; WeatherGPT unifies them into Forecast → Risk → Decision → Action, with evidence and context.”

## Honest scope statement
“GFS/WRF, WMO WIS, Bhashini and MQTT are production adapters in our architecture. The hackathon MVP uses a public live weather provider and browser voice APIs so the judges can run the prototype without credentials.”
